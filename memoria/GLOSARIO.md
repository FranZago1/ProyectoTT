# Glosario EN → ES-AR

Registro: español rioplatense formal, prensa económica argentina. Se aplica tal cual.
`python -m carrusel memoria <slug>` agrega al final los términos nuevos que cada carrusel registra en
`plan.json` (`glosario_nuevo`); cada alta nueva se justifica en `DECISIONES.md`.

## Formato

| Regla | Ejemplo |
|---|---|
| Coma decimal, punto de miles, espacio (duro) antes de % | 99.7% → 99,7 %; 10,000 → 10.000; 0.5 x 1.50 → 0,5 × 1,50 |
| Montos reales en dólares | $3.6 billion → US$ 3.600 millones; $100 billion → US$ 100.000 millones; $553 million → US$ 553 millones; trillion → billones |
| Montos de ejemplos hipotéticos | se mantiene «$» ($100, $150, $90) |
| Fechas | 17 de agosto de 1998 |
| Gráficos regenerados | ticks con formato argentino; gráficos conservados: ticks sin tocar |
| Comillas | “…” (tipográficas) |
| Guion largo | —inciso— (pegado al texto, estilo RAE) |

## No se traduce

Notación matemática (P(x), E(L), σ, g(f), f), VaR, ES, nombres propios (Ed Thorp, Ole Peters, Kelly,
Bell Labs, Bloomberg, Long-Term Capital Management, Berkshire Hathaway), instituciones sin traducción
establecida, handles, tickers, «S&P 500», «quants» (después de la primera mención).
